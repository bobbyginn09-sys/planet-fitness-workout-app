NEXSET 4.0.4 — JACKED + LEAN PLAN
Planet Fitness rolling five-day strength program

GOAL
Lose body fat while building a visibly larger upper body, bigger arms, stronger abs, and better overall strength without abandoning running.

WEEKLY EMPHASIS
• Direct biceps work: 10 sets, plus rows and pulldowns.
• Direct triceps work: 10 sets, plus all chest and shoulder pressing.
• Direct core work: 12 sets across three separate training days.
• Chest: 10 direct sets; back: 11 direct sets; shoulders/rear delts: 10 direct sets.
• Two lower-body days remain in the rotation.
• Required cardio stays controlled; the optional rest-day walk brings the full rotation near the 120-minute target.

DAY 1 — UPPER STRENGTH + ARMS
Chest, back, shoulders, biceps, triceps
  • Smith Machine Bench Press: 3×6–8 @ 145 lb · rest 150s
  • Lat Pulldown: 3×8–10 @ 90 lb · rest 120s
  • Incline Dumbbell Press: 2×8–12 @ 30 lb per dumbbell · rest 105s
  • Seated Cable Row: 2×8–12 @ 80 lb · rest 105s
  • Machine Shoulder Press: 2×8–12 @ 55 lb · rest 90s
  • Cable Curl: 3×10–15 @ 25 lb · rest 75s
  • Single-Arm Cable Triceps Pushdown: 3×10–15 @ 10 lb · rest 75s
  • Incline Treadmill Walk: 15 min · 2.8 mph · 6%
  Note: Eighteen working sets. The first two strength workouts use a reduced return ramp; after that, run the full growth plan with 1–3 clean reps in reserve.

DAY 2 — LOWER STRENGTH + CORE
Quads, hamstrings, glutes, calves, abs
  • Smith Machine Squat: 3×6–10 @ 135 lb · rest 180s
  • Smith Machine Romanian Deadlift: 3×8–10 @ 145 lb · rest 150s
  • Seated Leg Curl: 2×10–15 @ 50 lb · rest 90s
  • Leg Extension: 2×12–15 @ 25 lb · rest 75s
  • Calf Raise Machine: 2×12–20 @ 70 lb · rest 75s
  • Kneeling Cable Crunch: 3×10–15 @ 30 lb · rest 60s
  • Cable Pallof Press: 2×10–12 @ 10 lb · rest 60s
  • Easy Incline Treadmill Walk: 15 min · 2.7 mph · 4%
  Note: Seventeen working sets. Keep the Smith lifts controlled. The core work trains both loaded spinal flexion and anti-rotation instead of relying on random high-rep crunches.

DAY 3 — ACTIVE RECOVERY
Easy cardio, mobility, recovery
  • Easy Treadmill Walk: 25 min · 2.5 mph · 0%
  • Mobility Flow: 8–12 min
  • Stretching / Foam Rolling: 5–10 min
  Note: This is not a makeup lifting day. Keep the effort easy so the next hypertrophy block is productive.

DAY 4 — PUSH HYPERTROPHY + RUN
Chest, shoulders, triceps, running base
  • Machine Chest Press: 3×8–12 @ 90 lb · rest 105s
  • Machine Chest Fly: 2×12–15 @ 65 lb · rest 75s
  • Machine Shoulder Press: 3×8–12 @ 55 lb · rest 105s
  • Cable Lateral Raise: 3×12–20 @ 7.5 lb · rest 75s
  • Rope Triceps Pushdown: 3×10–15 @ 30 lb · rest 75s
  • Overhead Cable Triceps Extension: 4×10–15 @ 20 lb · rest 75s
  • Run / Walk Intervals: 5 rounds / 23 min · 6.0 mph run / 3.2 mph walk · 1%
  Note: Eighteen working sets. This is the main triceps-growth day. Use controlled reps and keep the run repeatable rather than turning it into a sprint test.

DAY 5 — PULL HYPERTROPHY + BICEPS + ABS
Back width, upper back, rear delts, biceps, abs
  • Chest-Supported Row Machine: 3×8–12 @ 70 lb · rest 105s
  • Neutral-Grip Lat Pulldown: 3×8–12 @ 75 lb · rest 105s
  • Cable Face Pull: 2×12–20 @ 15 lb · rest 75s
  • Dumbbell Hammer Curl: 3×8–12 @ 25 lb per dumbbell · rest 75s
  • Incline Dumbbell Curl: 4×10–15 @ 15 lb per dumbbell · rest 75s
  • Captain’s Chair Knee Raise: 3×10–15 bodyweight · rest 60s
  • Stair Climber: 12 min · level 5
  Note: Eighteen working sets. This is the main biceps-growth day. Keep rows and pulldowns strict so the arms are not already exhausted before curls.

DAY 6 — LOWER HYPERTROPHY + ABS
Quads, hamstrings, glutes, calves, abs
  • High-Foot 45° Leg Press: 3×10–15 @ 170 lb · rest 120s
  • Seated Leg Curl: 3×10–15 @ 55 lb · rest 90s
  • Leg Extension: 2×12–15 @ 40 lb · rest 75s
  • Hip Abductor Machine: 2×12–20 @ 80 lb · rest 75s
  • Calf Raise Machine: 3×12–20 @ 70 lb · rest 75s
  • Kneeling Cable Crunch: 4×10–15 @ 30 lb · rest 60s
  • Easy Treadmill Walk: 15 min · 2.6 mph · 2%
  Note: Seventeen working sets. Use moderate loads, longer controlled reps, and no lunges or hip thrusts. This is the second lower-body growth stimulus, not another max-strength day.

DAY 7 — FULL REST
Recovery, sleep, normal daily movement
  • Optional Easy Walk: 20 min · 2.4 mph · 0%
  • Light Stretching: 5–10 min
  Note: No required lifting. Let the rolling schedule move forward rather than cramming missed workouts together.

PROGRESSION
1. Keep most sets 1–3 clean reps short of failure.
2. Add repetitions inside the listed range before adding weight.
3. Increase weight only after every required set reaches the top of the range with controlled form.
4. The import includes a reduced return ramp for the first two strength workouts; afterward, use the full listed set targets and normal progression.
5. Preserved history may make NEXSET recommend one increment above a printable starting weight after the ramp; use the app target only when the prior set quality actually supports it.
6. Do not add more arm or ab sets for at least four complete rotations; first prove you can recover and progress on this volume.

ABS NOTE
The plan now trains the abs like any other muscle: loaded cable crunches, anti-rotation work, and controlled knee raises. Visible abs still depend on lowering overall body fat; ab exercises cannot selectively remove abdominal fat.
