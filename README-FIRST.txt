NEXSET 4.2.0 — JACKED + LEAN + NUTRITION

MAIN DEPLOYMENT
1. Export a backup from the currently installed NEXSET app.
2. Unzip NEXSET-4.2.0-DEPLOY-TO-CURRENT-REPO.zip.
3. Upload every file inside DEPLOY_TO_CURRENT_GITHUB_REPO to the root of the existing GitHub repository.
4. Let GitHub Pages publish.
5. Open the live site once with ?nexset=4.2.0 appended to the URL.
6. In NEXSET, open Profile > Backup & restore > Check for update > Update now.
7. Fully close and reopen the home-screen app.
8. Confirm the Profile screen says NEXSET 4.2.0 · Jacked + Lean + Nutrition.

DO NOT CREATE A NEW REPOSITORY
Keeping the existing repository preserves the current GitHub Pages path, installed-app scope, and the safest upgrade path for local data.

WHAT IS NEW
- Fifth bottom-navigation tab: Nutrition.
- Daily calorie, protein, carbohydrate, and fat tracking.
- Custom foods with serving multipliers, editing, deletion, date navigation, target editing, and Copy Yesterday.
- One-tap whey shake preset plus six author-listed cookbook meal presets.
- Nutrition is stored locally and travels inside normal NEXSET backup files.
- Starting targets: 2,400 calories, 200 g protein, 230 g carbohydrates, and 75 g fat.
- Easy post-lift cardio is attached to all five lifting workouts.
- Two optional evening-running opportunities remain; hard running stays away from leg days.
